# PRD + Skill: Redesign Alur Belanja Tokopedia

Repositori ini berisi **PRD** dan **Skill** untuk membangun prototype konsep redesign alur belanja Tokopedia (Project Vibe Code, mata kuliah Rekayasa Interaksi).

## Isi

| Berkas | Keterangan |
|---|---|
| `PRD.md` | Product Requirements Document lengkap (sama dengan repo PRD) |
| `.claude/skills/tokopedia-redesign-prototype/SKILL.md` | Skill yang memandu agen AI membangun dan memeriksa prototype dari PRD |
| `.claude/skills/tokopedia-redesign-prototype/references/ux-checklist.md` | Checklist pemeriksaan kebutuhan UX-01 sampai UX-07 |
| `.claude/skills/tokopedia-redesign-prototype/references/dummy-data.json` | Data dummy untuk prototype |

## Cara memakai

1. Buka repositori ini di Claude Code (atau agen coding lain yang mendukung skill).
2. Berikan perintah, misalnya: "Bangun prototype sesuai PRD.md memakai skill tokopedia-redesign-prototype."
3. Agen membaca PRD, membangun folder `prototype/`, lalu menjalankan checklist dan melaporkan hasilnya.
4. Buka `prototype/index.html` di browser, atau aktifkan GitHub Pages untuk membagikan link prototype.

## Catatan

Ini adalah konsep mahasiswa dan bukan dokumen atau produk resmi Tokopedia. Prototype memakai data dummy tanpa backend dan tanpa pembayaran nyata.
